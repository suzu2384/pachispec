# ぱちんこスペックライブラリ

ブラウザだけで使える、ぱちんこ機種スペックの個人用ライブラリです。サーバーやインストールは不要です。

## 使い方

1. `index.html` をブラウザで開きます。
2. 「機種を追加」から情報を登録します。
3. データはブラウザ内に自動保存されます。
4. 定期的に「データ管理」→「エクスポート」からバックアップしてください。

ブラウザのデータ削除や別PCへの移動に備え、設定を含むデータ全体のバックアップをおすすめします。復元は「データ管理」→「インポート」から行えます。

## 初期版の機能

- 機種カード一覧・詳細表示
- 新規登録・編集・削除
- 機種名・タグの検索
- 動画一覧と同じ方式のタグ管理（追加・名前変更・削除・機種への割り当て）
- タグによる絞り込み（複数タグはOR条件）
- 導入日、機種名、実質RUSH突入確率、初当り出球期待値による並び替え
- 特図1・特図2の大当り振り分け
- 通常時→RUSH→LTなどの状態遷移
- 自由なスペック項目の追加
- 初当り確率とRUSH突入率から実質RUSH突入確率を自動算出
- 特図1の振り分け率と出球から初当り出球期待値を自動算出
- 種類と補足を併記できるRUSH中当り確率
- 0.5刻みの5つ星評価（メイン項目・サブ項目の追加、名前変更、削除）
- 評価項目ごとの機種ランキング
- ブラウザ内への自動保存、機種・タグ・評価設定を含むデータ全体のバックアップ・復元
- タグ種類と評価項目を圧縮してURLへ保存
- PC・スマートフォン対応

## 指標の計算

実質RUSH突入確率は、次の式で表示します。

`初当り確率の分母 ÷ (RUSH突入率 ÷ 100)`

例：初当り 1/319.7、RUSH突入率 50% → 実質RUSH突入 約1/639.4

初当り出球期待値は、特図1の振り分けがすべて確定値なら自動計算します。可変出球や「＋α」を含む機種は、編集画面で「最低値」「概算」「確定値」「未算出」を選び、値と算出根拠を保存できます。最低値は「○個以上」、概算は「約○個」と区別して表示します。

## 10段階評価（0.5刻み）

画面上部の「評価項目」から、採点の軸を編集できます。初期状態では次の3項目が用意されています。

- 演出
- 出玉感
- RUSH

評価は5つ星を0.5刻みで入力できます。メイン項目には任意でサブ項目を追加でき、サブ項目があるメイン項目は、採点済みサブ項目の平均が評価になります。サブ項目がないメイン項目は直接評価します。

評価項目は`演出：先読み`のように`メイン項目：サブ項目`で登録します。`出玉感`のようにメイン項目だけを登録することもできます。

総合評価は入力項目ではなく、採点済みのメイン項目の平均値として自動計算されます。未評価の項目は平均計算から除外します。

機種カードの「評価」から、スペック編集を開かずに1〜5点を付けられます。「評価ランキング」では総合評価と各項目の順位を確認できます。評価項目の名前を変えても採点結果は引き継がれます。評価項目を削除すると、その項目で付けた点数も削除されます。

機種一覧のカードには先頭6件のメイン項目と総合評価が表示されます。カードの評価欄をクリックすると、そのまま評価を編集できます。7項目以上ある場合は、残りを機種の詳細画面上部で確認できます。

機種カード本体をクリックすると詳細を表示します。機種情報とタグの編集は、詳細画面上部から行えます。

## タグ

メーカー、P/e機、LTを専用項目ではなくタグとして管理します。画面上部の「タグ」に、絞り込みとタグ管理をまとめています。機種カードまたは機種編集画面の「タグ」から、登録済みタグを付け外しできます。

`メーカー：大都技研`、`P/e：e機`、`仕様：LT`のように`カテゴリ：項目`（半角コロンも可）で登録すると、カテゴリごとにまとまります。カテゴリ名のチェックで配下を一括選択でき、一部だけ選択した場合は中間状態で表示します。

以前のバージョンで登録したメーカー・P/e・LTの情報は、読み込み時に対応するタグへ自動変換されます。

## 注意

最初から入っている機種は操作確認用の架空データです。自由に編集・削除してください。

## ロゴ・ホーム画面アイコン

ヘッダーには採用デザインの輪郭をSVG化したロゴを使用しています。文字もパスで保持しているため、閲覧端末のフォントに左右されません。

- `assets/logo.svg`：文字付きロゴ
- `assets/mark.svg`：P・球・星のシンボル／SVG favicon
- `favicon.ico`、`assets/favicon-*.png`：小サイズ用favicon
- `assets/apple-touch-icon.png`：iPhone・iPad用180pxアイコン
- `assets/icon-192.png`、`assets/icon-512.png`：ホーム画面用アイコン
- `site.webmanifest`：ホーム画面での名前・アイコン・起動先

GitHub Pagesのサブディレクトリでも使えるよう、参照先は相対パスです。iPhoneではサイトを開き、「共有」→「ホーム画面に追加」で登録します。既存のホーム画面アイコンが更新されない場合は、登録し直してください。URLにタグ・評価項目の設定を含めている場合は、そのURLを控えてから登録し直してください。

ホーム画面追加用の設定であり、オフラインキャッシュ用のService Workerは追加していません。
